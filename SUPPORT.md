# Support

Start with the [README](README.md), [usage guide](docs/USAGE.md), and [CLI reference](docs/CLI.md). For reproducible software bugs, open an issue using the bug report template. For improvements or new model adapters, open a feature request or pull request with the target architecture and test evidence.

This is a research workbench. A model checkpoint, GPU environment, and task-specific dataset remain your responsibility. The maintainers cannot guarantee a behavioral result for a particular model.

For sensitive security reports, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
