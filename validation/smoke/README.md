# Recorded CLI-entrypoint smoke runs

These logs call the real CLI argument parser/dispatcher programmatically in one warmed Python process.
The actual models are small untrained dense and MoE PyTorch fixtures. Both automatic routing and explicit execution of every diagnostic stage were exercised.
They test software and tensor mechanics, not learned behavior or model quality.
State manifests are historical snapshots; this directory is not a resumable full run.
No Qwen, RTX 3060, TPU or downloaded model inference is implied.
