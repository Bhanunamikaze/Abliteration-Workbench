# Llama 3.2 refusal-metric evidence index

This directory publishes a small audit trail for the [research record](../../docs/research/llama32-refusal-2026-10-04.md). It contains scores and provenance, without model weights, learned directions, prompts, or full generated responses. These are records of one local, same-environment comparison, not independent semantic labels or an external-lab replication.

| File | What it establishes | Provenance |
|---|---|---|
| [replication-summary.json](replication-summary.json) | The Workbench's recorded aggregate metrics, gates, status, and provenance | **Byte-for-byte copy** of `runs/llama32-refusal-replication/summary.json`; SHA-256 `87f7649b362730e85838292459e0ee262fa280e137df5ad4d874d0966207096d` verified before copying. It retains original local paths because changing them would change the source file. |
| [publication-audit.json](publication-audit.json) | Exposure counts, one concrete scorer error, review limits, and policy timing | Separately derived during publication review from the saved datasets and paired outputs; not a historical result rewrite. |
| [paired-labels.csv](paired-labels.csv) | All 292 aligned baseline/intervention score pairs and review flags | Derived by ID from the four first-class output files and the replication dataset. It has no prompt or response text and is **not human annotated**. |
| [research-stage-summary.json](research-stage-summary.json) | Selected pilot, censoring, confirmation, and eight-prompt evaluation fields | Derived excerpts from the source stage results; source file SHA-256 values are embedded. |
| [package-replay-excerpt.json](package-replay-excerpt.json) | Manifest fields recording unchanged weights and 292 exact saved-token matches | Sanitized subset of the existing bundle manifest; its original SHA-256 is included. The replay was recorded at packaging time, not rerun for this publication. |
