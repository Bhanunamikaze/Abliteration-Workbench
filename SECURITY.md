# Security reporting

Security reports for the Abliteration Workbench code are welcome. The supported version is the current `main` branch; older commits and third-party model weights are not maintained here.

Report a suspected vulnerability privately through the [maintainer contact page](https://www.hackingdream.net/p/contact-us.html). Include the affected commit or version, a minimal reproduction, expected and observed behavior, and potential impact. Do not put exploit details, credentials, private datasets, or model weights in a public issue. We will review reports as maintainer capacity allows and coordinate disclosure with the reporter.

For ordinary bugs, use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md). For vulnerabilities in a dependency or model checkpoint, also notify its upstream maintainer. Do not test systems or services you do not own or have permission to assess.
